# 你好，我是 Coulson

住在上海，正在边学边做一些小项目。这里放的东西大多从具体用途开始：让 Mac 上跑完的任务通知到手机，整理一个能自己维护的个人网站，或者做一个有自己样子的桌面角色。

## App 作品

- [星语塔罗 · 产品与使用手册](https://coulson-joyful.github.io/apps/tarot/)：每日一牌、牌阵、占星骰、一页回应与主题牌面展示。
- [GreenTune · 产品与使用说明](https://coulson-joyful.github.io/apps/greentune/)：调音器、节拍器与变速练习，附多设备使用说明。

两个 App 均处于开发与上架准备阶段。这里展示产品文档和界面，源码工程保持私有。

## 可以从这几个项目逛起

- [codex-iMessage-notify](https://github.com/Coulson-joyful/codex-iMessage-notify)：用 iMessage 发起独立 Codex 任务，或接收电脑上任务的完成与授权提醒。
- [claude-iMessage-notify](https://github.com/Coulson-joyful/claude-iMessage-notify)：给自己发一条消息，让 Mac 上的 Claude 执行，再把结果送回手机。
- [玄骨](https://github.com/Coulson-joyful/codex-pet-xuangu)：浅蓝长袍、掌心灵火的动态宠物，仓库里有图集、安装脚本和检查记录。
- [个人网站](https://coulson-joyful.github.io)：静态 HTML、CSS 和 JavaScript 写的主页；[源码](https://github.com/Coulson-joyful/Coulson-joyful.github.io)也在这里。

这些项目的安装方式和使用限制都写在各自 README 里。有些依赖 Mac 本机权限，有些还在调整，我会把已经能做的和还要验证的分开写。
